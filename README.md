# FG Downloader

A fast, minimal, and native desktop downloader for FitGirl Repacks. 
It bypasses P2P torrenting entirely by scraping, resolving, and sequentially downloading from direct file hosters.

## Features
- **Smart Search**: Type a game's name to query the database and select from available versions.
- **Direct Link Resolution**: Automatically handles filehoster URLs behind the scenes.
- **Selective Downloads**: Choose exactly which optional packages and language files to include.
- **Smart Resume**: Interrupted downloads automatically skip completed chunks upon resuming.
- **History System**: Saves your recent sessions. Click "Load" to restore your target directory and pick up right where you left off.
- **Minimal UI**: Built with Dear PyGui for a lightweight, hardware-accelerated, and frameless interface.

## Usage
1. Run `FG Downloader.exe`
2. Enter a game name or paste a URL.
3. Select your preferred file provider and any optional files.
4. Click Start Download.
